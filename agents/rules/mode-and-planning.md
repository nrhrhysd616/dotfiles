# 計画とモード管理

以下のいずれかに該当するタスクは、着手前に計画を提示して合意を取ること:

- 3ファイル以上にまたがる変更が予想される
- 新機能の追加・大規模リファクタリング
- 要件が曖昧で調査フェーズが必要な場合
- 複数の実装アプローチが考えられる場合

Claude Code では `EnterPlanMode` でplanモードへの移行を提案する。
planモードを持たないエージェントでは、計画を文章で提示し承認を得てから着手する。
