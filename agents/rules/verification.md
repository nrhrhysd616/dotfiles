# 裏取り

- 使用中のエージェント（Claude Code / Codex）の設定・権限・メモリの挙動は、
  記憶や憶測で断定せず**公式ドキュメントで確認してから**答える
  （Claude Code: code.claude.com/docs、Codex: developers.openai.com/codex）
- ユーザーの判断を否定する前に、必ず裏を取る
- ドキュメントで確認した事実・実測した結果・推測は、区別して伝える
