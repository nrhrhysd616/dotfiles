# 実行環境の制約

- **sudo はエージェントから実行できない。** シェルツールからも `!` プレフィックスからも
  TTY が割り当てられず `sudo: a terminal is required to read the password` で失敗する。
  処理をまとめた**冪等な** zsh スクリプトを `~/` など短いパスへ書き出し、
  ユーザーにターミナルで `sudo zsh ~/script.zsh` を実行してもらう。
  実行後は読み取り専用コマンドで結果を検証する。`sudo -S` でパスワードを渡そうとしない
- **Homebrew で入る CLI ツールを `brew install` しない。** 端末に入るツールは dotfiles
  リポジトリ側で宣言的に管理されており、エージェントが直接入れると管理外の差分になる。
  `which <tool>` で未インストールと分かったら、その場で入れずに**ツール名を伝えて導入を待つ**。
  `pnpm install` などプロジェクト内で完結するパッケージ導入は対象外
